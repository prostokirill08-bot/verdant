# Запуск без вложений (0 ₽)

Бизнес работает через **Telegram-бота с вашего компьютера**. Сервер и домен не нужны.
Когда пойдут продажи — переезд на сервер по DEPLOY.md (около часа).

## Что нужно
- Компьютер с Windows 10/11 (или macOS/Linux) и **Docker Desktop** (бесплатно).
- Telegram.
- Карта с СБП — сюда клиенты переводят оплату.
- Статус самозанятого и приложение «Мой налог» (для чеков).

## Шаги (≈ 20 минут)
1. **Скачайте проект:** github.com/prostokirill08-bot/verdant → переключите ветку на `claude/autonomous-ai-business-8t9and` → Code → Download ZIP → распакуйте.
2. **Создайте бота:** в Telegram откройте @BotFather → `/newbot` → придумайте имя и username → скопируйте токен.
3. **Запустите** в папке `vitrinalab` файл **`start-local.bat`** (macOS/Linux: `./start-local.sh`).
   Откроется Блокнот с настройками — впишите:
   - `TELEGRAM_BOT_TOKEN=` токен из шага 2;
   - `MANUAL_PAYMENT_DETAILS="Перевод по СБП на номер +7…, банк …, получатель Имя О."`;
   - `OWNER_FULL_NAME=`, `OWNER_INN=`, `OWNER_EMAIL=` — для оферты.
   Сохраните, закройте Блокнот. Первый запуск собирается 5–10 минут.
4. В конце откроется админка (`http://localhost:8000/admin`, логин `admin`, пароль покажет окно запуска).
   В разделе **Настройки** есть команда `/owner …` — **отправьте её своему боту**. Теперь отчёты и кнопки подтверждения оплат приходят вам в Telegram.
5. Проверьте сами: напишите боту `/start`, пришлите фото товара и факты — через пару минут придёт превью.

## Как идут деньги
Клиент выбирает тариф → бот присылает ваши реквизиты СБП → клиент переводит и жмёт «Я оплатил(а)» →
вам приходит сообщение с кнопками **«✅ Деньги пришли» / «❌ Не вижу»** → после «Деньги пришли» заказ
делается и доставляется в Telegram автоматически. После каждой оплаты пробейте чек в «Мой налог»
(список — админка → Финансы).

## Ограничения режима
- Бот отвечает, **пока компьютер включён** и запущен Docker Desktop. Отключите спящий режим; в Docker Desktop включите «Start when you sign in».
- Сайта нет — клиенты приходят через ссылку на бота: `https://t.me/<бот>?start=src_<канал>`.
- ЮKassa требует сайт — пока оплата только переводом по СБП.
- AI-тексты: без ключей работает запасной алгоритм (только ваши факты, шаблонно). Бесплатно подключить: у Yandex Cloud есть стартовый грант для новых аккаунтов, у GigaChat API — бесплатный пакет для физлиц (условия уточните на их сайтах). Ключи — в `.env`, затем `start-local.bat` ещё раз.

## Управление с телефона (через бота)
Из чата владельца (после `/owner`) доступны команды — клиенты их не видят:
| Команда | Что делает |
|---|---|
| `/stats` | цифры за сегодня и за всё время |
| `/orders` | последние заказы + кнопки: «Пилот бесплатно», «Оплачено на бирже», «СБП-оплата пришла», «Перезапустить», «Отправить снова» |
| `/approvals` | сообщения лидам и посты — кнопки «Одобрить / Отклонить / Отправил(а)» |
| `/receipts` | оплаты для чеков в «Мой налог» — кнопка «Чек пробит» |
| `/report` | ежедневный отчёт прямо сейчас |
| `/mode chatgpt` / `/mode auto` | картинки делаете вы в ChatGPT по промптам бота / система автоматически |
| `/jobs` | задания для ChatGPT, которые ждут картинок |
| `/reset` | обнулить все данные после тестов (с подтверждением и резервной копией) |

### Режим ChatGPT — как выполнять задание
1. Бот присылает фото товара (файлом), референс клиента (если есть) и промпты — по одному сообщению на картинку.
2. В ChatGPT: загрузите фото → отправляйте промпты по очереди → сохраняйте картинки.
3. В боте: «📥 Прислать картинки» → отправьте картинки по порядку (лучше файлом, без сжатия) → «готово».
4. Сверьте товар с оригиналом (ChatGPT любит перерисовывать узоры и детали) → «✅ Отправить клиенту».
Новые черновики сообщений лидам и посты бот присылает на одобрение сам.

## Остановить / обновить
- Остановить: `stop-local.bat`. Данные сохраняются.
- Обновить: `update-local.bat` — скачает свежую версию, сохранит `.env` и данные, пересоберёт (1–3 мин).

## Когда переезжать на сервер
Когда есть стабильные оплаты (например, ≥5 в неделю) или пропущенные из-за выключенного компьютера заявки.
Сервер + домен ≈ 2–3 тыс ₽/мес — окупаются одним заказом. Инструкция — DEPLOY.md.

## Поиск заказов (с версии 0.8.0)
Каждые 30 минут бот сам проверяет публичную ленту заказов на инфографику и присылает вам карточку:
текст заказа, ссылка, готовый отклик и кнопки «📤 Откликнулся» / «🚫 Не подходит».
Найдите заказ по названию на Kwork → Биржа или на FL.ru, вставьте отклик и нажмите кнопку — так считается воронка.
Отключить: в `.env` строка `SCOUT_CHANNELS=` (пусто) и перезапуск.

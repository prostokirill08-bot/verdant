# CHANGELOG

## 0.2.0 — 2026-11-06
- Развёртывание одной командой: `deploy/bootstrap.sh` (Docker из репозитория Ubuntu, зеркало реестра, файрвол, генерация секретов, Caddy с автоматическим HTTPS, бэкап в cron), `deploy/update.sh`.
- Самопроверка подключений `python -m app.check`.
- Привязка владельца командой `/owner <код>`; автонастройка описания и команд бота.
- Админка: «Пилот (бесплатно)» и «Оплачено на бирже».
- Исправлено (найдено при сборке Docker): конфликт uid пользователя в образе Playwright; воркер падал, если PostgreSQL ещё не готов; гонка создания таблиц при одновременном старте web и worker.
- DEPLOY.md (пошагово для владельца), LAUNCH_KIT.md (тексты для пилотов, бирж, партнёров, план 14 дней).

## 0.1.0 — 2026-11-06
Первая рабочая версия MVP (не развёрнута).
- Исследование рынка, выбор модели, одобрение владельцем (Россия, самозанятый).
- Ядро: модели данных, очередь задач с повторами и идемпотентностью, планировщик, журнал событий, эскалации.
- Производство: вырезка товара (заливка фона / U²-Net / рамка), 8 палитр, макеты обложек (3 варианта), преимуществ, характеристик, особенностей, списков; авто-подгонка текста; рендер 1440×1920.
- Копирайтер с YandexGPT/GigaChat и детерминированным запасным алгоритмом.
- QC: закон о рекламе, правила площадок, запрет выдуманных чисел, формат файлов, авто-доработка.
- Платежи: ручной СБП и ЮKassa (вебхук с перепроверкой, защита от повторов и подмены суммы).
- Telegram-бот: продажи, поддержка, доставка, правки, эскалации; deep-link метки каналов.
- Сайт: лендинг, форма превью, личный кабинет, оферта и политика ПД (черновики).
- Админка/CRM: сводка, воронка, лиды, одобрения, клиенты, заказы, агенты, очередь, финансы, эскалации, настройки.
- Ежедневный отчёт (18 пунктов), аналитика воронки, контент-план.
- Docker (web + worker + Postgres), бэкапы, `/healthz`.
- 14 автотестов.

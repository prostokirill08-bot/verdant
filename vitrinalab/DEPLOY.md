# Запуск на сервере — пошагово (≈ 1 час)

Всё ниже делаете вы: покупки и аккаунты оформляются на ваше имя. Секреты (токены, ключи, пароли)
вписываются только в файл `.env` на сервере — **не присылайте их в чат**.

## 1. Сервер (≈ 1–2 тыс ₽/мес)
Любой провайдер с дата-центром в РФ (152-ФЗ): Timeweb Cloud, Selectel, Yandex Cloud и т.п.
- ОС: **Ubuntu 24.04** (или 22.04)
- **2 vCPU, 4 ГБ RAM, 30+ ГБ диска**, публичный IPv4
- Доступ: root по паролю или SSH-ключу

## 2. Домен (≈ 200–900 ₽/год)
Купите домен (.ru) у любого регистратора (REG.RU, RU-CENTER, у самого хостинга).
В DNS добавьте две записи **A**: `@` → IP сервера и `www` → IP сервера. Применяются от 5 минут до нескольких часов.

## 3. Установка одной командой
С компьютера (Windows: PowerShell; macOS: Терминал):
```bash
ssh root@<IP_сервера>
curl -fsSL https://raw.githubusercontent.com/prostokirill08-bot/verdant/claude/autonomous-ai-business-8t9and/vitrinalab/deploy/bootstrap.sh -o bootstrap.sh
sudo bash bootstrap.sh <ваш-домен.ru>
```
Скрипт ставит Docker, файрвол, код, генерирует секреты, выпускает HTTPS-сертификат, запускает сайт, воркер и БД,
включает ежедневный бэкап и в конце печатает **пароль админки — сохраните его**.
Проверка: откройте `https://<домен>` и `https://<домен>/admin` (логин `admin`).

## 4. Telegram-бот (5 минут)
1. В Telegram откройте **@BotFather** → `/newbot` → имя «ВитринаЛаб» → username, например `vitrinalab_bot`. Скопируйте токен.
2. На сервере: `cd /opt/verdant/vitrinalab && nano .env` → `TELEGRAM_BOT_TOKEN=<токен>` → сохранить (Ctrl+O, Enter, Ctrl+X).
3. `docker compose up -d` — описание и команды бота настроятся автоматически.
4. Откройте админку → **Настройки**: там будет команда вида `/owner 1a2b3c4d`. Отправьте её боту — ваш чат станет чатом владельца для отчётов и эскалаций.
5. (Опционально) Создайте канал, добавьте бота администратором, впишите `TELEGRAM_CHANNEL_ID=@имя_канала`.

## 5. Приём оплаты
**Старт — ручной режим (без договоров):** в `.env` впишите
`MANUAL_PAYMENT_DETAILS="Перевод по СБП на номер +7…, банк …, получатель Имя О."`.
Клиент переводит и нажимает «Я оплатил(а)» → вам приходит эскалация → проверяете поступление → админка → Заказы → «Подтвердить ручную оплату» → заказ уходит в производство автоматически.

**Затем — ЮKassa** (подключение для самозанятых на сайте ЮKassa): получите `shopId` и секретный ключ →
`PAYMENT_PROVIDER=yookassa`, `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` → в личном кабинете ЮKassa укажите
HTTP-уведомления: `https://<домен>/webhooks/yookassa`, событие `payment.succeeded`.

После каждой оплаты пробейте чек в приложении **«Мой налог»** (список — админка → Финансы → «Чеки к регистрации»).

## 6. Реквизиты для оферты
В `.env`: `OWNER_FULL_NAME`, `OWNER_INN`, `OWNER_EMAIL`. Прочитайте `/offer` и `/privacy` на сайте — это черновики, лучше показать юристу.

## 7. AI (Yandex Cloud) — можно позже
Без ключей тексты собирает запасной алгоритм (только ваши факты, шаблонно). С YandexGPT тексты живее.
1. console.yandex.cloud → создайте платёжный аккаунт и каталог; скопируйте **ID каталога**.
2. Сервисные аккаунты → создать → роль `ai.languageModels.user` (и `ai.imageGeneration.user` для фонов).
3. В аккаунте → «Создать API-ключ» → скопируйте ключ.
4. В `.env`: `LLM_PROVIDER=yandex`, `YANDEX_API_KEY=…`, `YANDEX_FOLDER_ID=…` (для фонов: `IMAGE_PROVIDER=yandexart`).
5. Сверьте цены токенов с тарифами Yandex Cloud и при необходимости поправьте `LLM_PRICE_*` — от них считается себестоимость.
Дневной лимит расходов на AI: `DAILY_AI_BUDGET_RUB` (по умолчанию 500 ₽; сверх — агенты переходят на запасные алгоритмы).

## 8. Проверка
```bash
cd /opt/verdant/vitrinalab && docker compose up -d && docker compose exec worker python -m app.check
```
Все пункты должны быть ✅ (⚠️ — необязательные). Затем сделайте тестовый заказ сами: `/start` в боте → фото → факты.

## 9. Мониторинг
Зарегистрируйтесь в любом бесплатном сервисе проверки доступности (например, UptimeRobot) и добавьте
`https://<домен>/healthz` — ответ 503 значит, что воркер не работает.

## Обслуживание
| Задача | Команда (в `/opt/verdant/vitrinalab`) |
|---|---|
| Обновить код | `sudo bash deploy/update.sh` |
| Применить изменения `.env` | `docker compose up -d` |
| Логи | `docker compose logs -f worker` / `web` |
| Перезапуск | `docker compose restart` |
| Бэкапы | `/var/backups/vitrinalab` (ежедневно 04:30, 14 дней) |

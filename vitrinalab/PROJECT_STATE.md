## Что работает (проверено тестами и вручную в браузере)
- Сайт: лендинг, форма бесплатного превью, личный кабинет заказа, оферта и политика ПД (черновики).

- Полное производство: копирайтинг (LLM или детерминированный запасной алгоритм) → 5–8 слайдов + варианты обложки → QC → одна авто-доработка → ZIP + SEO.txt.
- QC блокирует: «лучший/самый/№1», цены, ссылки, телефоны, e-mail, медицинские обещания, **числа, которых нет в данных клиента**, переполнение текста, неверный размер.

## Известные ограничения
- Без ключей Yandex Cloud тексты делает детерминированный алгоритм: грамотно, но шаблонно (перестановка фактов клиента).
- Реальные API Yandex/GigaChat/ЮKassa/Telegram в песочнице разработки недоступны — интеграции проверены на подменённых ответах по документации; первый реальный вызов проверить после подключения ключей.
- Бот не может писать лидам первым (ограничение Telegram) — первые сообщения лидам владелец отправляет вручную после одобрения.
- Загрузка результата в карточку через API Ozon/WB не реализована (в TODO).
- Подписка «Пакет на месяц» — разовый платёж за пакет, не рекуррентное списание.
- Репозиторий публичный: секретов в коде нет (только в .env на сервере), но код бизнеса виден всем. Можно сделать приватным — bootstrap поддерживает deploy-ключ.
- Docker Hub ограничен из РФ: bootstrap настраивает зеркало mirror.gcr.io. Если зеркало будет недоступно — заменить в /etc/docker/daemon.json.
